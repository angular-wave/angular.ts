# AngularTS Native HarmonyOS Core

Host AngularTS in ArkWeb and render declared native elements on the ArkUI same-layer surface.

## Install

```sh
ohpm install @angular-wave/angular-native-harmony-core@0.37.0
```

## Use

```ts
import { AngularNativeDestination, AngularNativeWeb } from "@angular-wave/angular-native-harmony-core";
```

This package is part of [AngularTS](https://github.com/angular-wave/angular.ts). The [HarmonyOS integration guide](https://github.com/angular-wave/angular.ts/tree/master/integrations/harmonyos) covers project setup, security, compatibility, and release checks.
