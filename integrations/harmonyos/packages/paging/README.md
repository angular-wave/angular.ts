# AngularTS Native HarmonyOS Paging

Apply keyed insert, move, update, and remove operations to lazy native collections.

## Install

```sh
ohpm install @angular-wave/angular-native-harmony-paging@0.36.0
```

## Use

```ts
import { KeyedNativeCollection } from "@angular-wave/angular-native-harmony-paging";
```

This package is part of [AngularTS](https://github.com/angular-wave/angular.ts). The [HarmonyOS integration guide](https://github.com/angular-wave/angular.ts/tree/master/integrations/harmonyos) covers project setup, security, compatibility, and release checks.
