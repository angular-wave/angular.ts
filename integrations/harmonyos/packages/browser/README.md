# AngularTS Native HarmonyOS Browser routes

Open external HTTP and HTTPS locations through HarmonyOS while keeping packaged AngularTS routes in ArkWeb.

## Install

```sh
ohpm install @angular-wave/angular-native-harmony-browser@0.36.0
```

## Use

```ts
import { HarmonyBrowserRoute } from "@angular-wave/angular-native-harmony-browser";
```

This package is part of [AngularTS](https://github.com/angular-wave/angular.ts). The [HarmonyOS integration guide](https://github.com/angular-wave/angular.ts/tree/master/integrations/harmonyos) covers project setup, security, compatibility, and release checks.
