# AngularTS Native HarmonyOS Navigation

Mirror AngularTS route operations into an ArkUI NavPathStack without moving route ownership out of AngularTS.

## Install

```sh
ohpm install @angular-wave/angular-native-harmony-navigation@0.36.0
```

## Use

```ts
import { HarmonyNavigation, HarmonyNavPathPlatform } from "@angular-wave/angular-native-harmony-navigation";
```

This package is part of [AngularTS](https://github.com/angular-wave/angular.ts). The [HarmonyOS integration guide](https://github.com/angular-wave/angular.ts/tree/master/integrations/harmonyos) covers project setup, security, compatibility, and release checks.
