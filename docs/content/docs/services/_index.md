A service is one reusable object or function that AngularTS can provide to
controllers, components, directives, and other services. The act of requesting
that service by name is called dependency injection.

Start with [shared models]({{< relref "/docs/services/models" >}}), then choose
the guide for the feature you need. Use the [service
reference]({{< relref "/docs/service" >}}) when you already know a service token
such as `$http`.
