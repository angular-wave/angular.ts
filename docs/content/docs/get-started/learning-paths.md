## What you will learn

This page selects the shortest route from the beginner tutorial to your goal.

## Before you start

Complete [how AngularTS
works]({{< relref "/docs/get-started/how-angular-works" >}}) or be comfortable
with modules, scopes, directives, and reactive updates.

## Build with HTML templates

Read [template views]({{< relref "/docs/views/templates" >}}), then the
[form]({{< relref "/docs/guides/forms" >}}) and
[server-data]({{< relref "/docs/guides/server-data" >}}) guides.

## Build with type-safe views

Read [typed views]({{< relref "/docs/views/typed" >}}), then [collections and
cleanup]({{< relref "/docs/views/collections-and-cleanup" >}}).

## Build a multi-screen application

Read [application
structure]({{< relref "/docs/guides/application-structure" >}}) and then
[routing]({{< relref "/docs/guides/routing" >}}).

## Move an existing application

Use the [migration guide]({{< relref "/docs/migration" >}}). It separates
AngularJS-compatible concepts from AngularTS replacements.

## Use another language

Use the [integration guide]({{< relref "/docs/integrations" >}}) after learning
the runtime concepts in this tutorial.

## Optimize and standardize an application

Use the [cookbook]({{< relref "/docs/cookbook" >}}) after the first feature is
working. Start by measuring, then apply the narrowest relevant recipe. Adopt the
application style guide before multiple contributors add components.
