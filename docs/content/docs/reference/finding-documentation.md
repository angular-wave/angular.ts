Use documentation by intent:

- **New to AngularTS:** start with [Get started](/docs/get-started/), then
  complete the [task-board tutorial](/docs/tutorial/).
- **Building a feature:** use [Guides](/docs/guides/) for forms, routing, server
  data, testing, and production.
- **Choosing an architecture:** use [Choose an approach](/docs/decisions/).
- **Learning a concept:** use [Concepts](/docs/concepts/).
- **Looking up behavior:** use singular directive, service, filter, and value
  reference sections.
- **Using another language:** use [Integrations](/docs/integrations/).
- **Fixing a failure:** start with the [error catalog](../errors/) and
  [troubleshooting guide](/docs/guides/troubleshooting/).

Plural sections such as **Directives** and **Services** teach workflows.
Singular sections such as **Directive** and **Service** are feature reference.
