Start with [Migrate from AngularJS]({{< relref "/docs/migration/from-angularjs" >}}).
Use the current API documentation as the source of truth rather than carrying
removed providers or aliases into new code.

Migrate one feature at a time and keep user-visible tests around that boundary.
